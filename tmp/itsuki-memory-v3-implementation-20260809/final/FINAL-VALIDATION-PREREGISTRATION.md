## Stage C - local long-history scale (no inference)

Populate isolated local D1 fixtures at 1k, 10k and 100k rows using production
schema and deterministic synthetic text. Measure scoped episode FTS, semantic

Gate: no scope error or unbounded result/context, deletion leaves zero live/FTS
rows, and the scaling frontier is reported honestly. No arbitrary latency PASS

## Stage D - repeated final non-LoCoMo holdout

Three independent fresh ingestion seeds, sequentially, on the same frozen
inputs and ten clean treatment slots. Each seed uses the complete candidate,
answers 42 questions at depth 200, seals products, then loads references and
judges with GPT-OSS-120B. Cleanup to zero occurs between seeds.

Report per seed and aggregate: capture recall/precision/F1, schema validity,
atom/event/edge variance, judge, token-F1, availability, conditional and absent
accuracy, categories, context items/tokens, ingest/recall/reader latency,
storage and neurons. Stage hard cap: 90,000 neurons.

General acceptance gates: zero security/durability/accounting failure; mean
capture precision >=95%; mean judge >=80%; no seed judge below 75%; mean
evidence availability >=75%; no category collapses by >15pp against its paired
accepted-path historical evidence. If LoCoMo later rises while this holdout
fails, V3 is not accepted.

## Stage E - one decisive complete frozen LoCoMo

Use the clean middle ten campaign slots and isolated project
`v3-final-locomo`; never alter the preserved d04 state. One fresh accepted-path
ingestion only. Then answer and judge all 1,540 frozen non-adversarial questions
at depth 200 with GPT-OSS-120B and exact E9A expansion. No reranker, E9B, E10,
re-ingest, prompt tuning, reference inspection or seed cherry-picking.

Report official token-F1, LLM-judge, evidence availability, conditional and
absent accuracy, single-hop/multi-hop/temporal/open-domain, selected/rendered
items and assertions, context size, ingest/recall/reader/judge latency, storage,
calls/neurons and integrity counts. Stage hard cap: 500,000 neurons.

The 60-70% target is not a gate. The result is accepted as measurement only if
all 1,540 products/verdicts reconcile, hashes and state are sealed, model/path
guards pass and there is no leakage. If score is below the valid E1+E0 46.75%
baseline, architecture quality becomes CONDITIONAL/FAIL according to holdout
and failure-stage evidence; there is no benchmark-specific retuning or repeat.
