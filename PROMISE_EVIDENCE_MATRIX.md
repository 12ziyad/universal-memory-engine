## Known implementation defects found by this audit (code, NOT copy)

This pass was copy-only by instruction. Two real defects were found and deliberately NOT fixed:

1. **The account-deletion confirmation email never sends.** cleanup.js:1411 guards on user?.email, but user is selected at :877 as "SELECT id, email_normalized" — there is no email field, so the guard is always false and account_deletion_done is never enqueued. No public copy promises this email, so it is an unkept internal commitment rather than a false public claim.
2. **mail_outbox is never scrubbed at account erasure.** lifecycle_census.js classifies it "scrub", but deleteAccountCompletely never touches it, so a plaintext recipient address and rendered body survive erasure. The Privacy copy now discloses this; the durable fix is to scrub the table.
